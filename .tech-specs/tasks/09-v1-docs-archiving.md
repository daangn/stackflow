> **우선순위: 선택적** — v2 릴리스 이후 별도 논의 후 진행 가능

## 목적

v1 → v2 마이그레이션으로 기존 문서가 삭제/교체되고 있어, v1을 사용 중인 사용자가 과거 API 문서를 참조할 방법이 없다.
[React Router](https://reactrouter.com/home)처럼 버전별 문서를 열람할 수 있는 구조를 지원해 마이그레이션 부담을 줄인다.

## 옵션

### 옵션 A. 버전 셀렉터 (권장)

문서 사이트 상단에 v1/v2 셀렉터 추가. Next.js 라우팅 + Nextra 구조에서 버전별 페이지 트리 분리.

### 옵션 B. 경로 아카이빙

v1 문서를 `/v1/...` 경로에 그대로 보존. v2는 기존 경로(`/docs/...`)에 유지.

### 옵션 C. 별도 브랜치 배포

`v1-docs` 브랜치에서 v1 문서 사이트 별도 배포 (예: v1.stackflow.so). Cloudflare 배포 라우팅 조정 필요.
