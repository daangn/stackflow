# useFlow 순환참조 해결하기

Stackflow 2.0에서는 `useFlow()`와 `useStepFlow()`를 `@stackflow/react`에서 직접 import하기 때문에 대부분의 경우 순환참조 문제가 더 이상 발생하지 않아요.

만약 `useActions()`를 감싸는 커스텀 래퍼를 만들고 액티비티 타입을 참조해야 한다면, stackflow 설정에서 타입을 export할 수 있어요.

```tsx showLineNumbers filename="stackflow.ts" copy
import { stackflow } from "@stackflow/react";
import { config } from "./stackflow.config";

export const { Stack } = stackflow({
  config,
  components: {
    // ...
  },
});
```

```tsx showLineNumbers filename="useMyFlow.ts" copy
import { useActions } from "@stackflow/react";
import { config } from "./stackflow.config";

export const useMyFlow = () => {
  return useActions(config);
};
```

<Callout emoji="💡">
  액티비티 간 탐색이 목적이라면, `@stackflow/react`에서 직접 import한 `useFlow()`를 사용하면 돼요. 별도의 래퍼가 필요 없어요.
</Callout>
